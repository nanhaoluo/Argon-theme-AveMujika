Mermaid 换行符测试

测试 WP-Markdown 生成的 HTML 中 <br> 标签是否正确转换为换行符

测试 1: 模拟 WP-Markdown 格式（带 <br> 标签）

::: mermaid
flowchart TD
Start([开始]) --> Process[处理]
Process --> End([结束])
:::

测试 2: 复杂流程图（多行文本）

::: mermaid
flowchart TD
A[用户提交评论] --> B{启用 AI 检测?}
B -->|是| C[AI 检测]
B -->|否| D[直接保存]
C --> E{检测结果?}
E -->|垃圾评论| F[移入回收站]
E -->|正常评论| G[保存评论]
:::
